# Reference material

The integration example contains a snapshot of **Why macOS pauses your apps when
swap runs out**, by Marian Posăceanu, and the article's styles, site script,
illustration, favicon, and fonts:

https://ark.marianposaceanu.com/macos-swap-exhaustion-paused-apps

This copy was requested for testing the library against the complete article.
`examples/article.source.html` preserves the downloaded source; generated
examples identify themselves as local integration examples and link back to the
original. Relative article navigation is resolved to the original site.
